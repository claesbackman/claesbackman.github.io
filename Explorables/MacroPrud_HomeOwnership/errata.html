Errata and notes

Errata

No errata have been recorded for the current version. If you find an error, use the "Report a bug" link at the top of any page; it opens an issue in the repository with the page already filled in.

Notes on the digital edition

The text, tables and figure captions are generated from the LaTeX source of the working paper. Tables show the paper's numbers. Figures are drawn from the estimates that the robustness scripts re-ran on the current data, so that every figure can be rescaled, switched to a table and traced to its specification in the explorer. Where the website version of a figure differs from the paper's, the figure notes say so. Known differences:

  • Appendix Figure A3 (iMaPP database) uses the cumulative response and the Eurostat or BIS control sets; the paper's version used year-on-year changes with the BIS controls.
  • Appendix Table B23 (depth of the mortgage market): the explorer's estimates for the deep and shallow splits without controls differ from the printed table by up to 0.02 percentage points, while the rows with controls match exactly. The source of the difference has not been traced; the signs and significance levels are unchanged.
  • Two-way clustered standard errors are reported in the explorer but not in the paper; with fifteen year clusters the estimated variance is sometimes not positive, in which case the explorer shows "n/a".

Software

Estimates: Stata 18.5 with reghdfe, boottest, xtscc, csdid and drdid. Site: pandoc 3.8, Python 3, D3 7.9, KaTeX 0.16. The robustness grid on this site was estimated on 23 October 2026.

Revision history
