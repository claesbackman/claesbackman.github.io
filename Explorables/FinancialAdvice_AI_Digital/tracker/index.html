Advice Drift Tracker

Every wave re-asks one question — what share of $50,000, stated in the local currency equivalent, a 40-year-old investing over five years should put in a broad stock index fund rather than government bonds — of a panel of models, in English: one English prompt per country, repeated 25 times per model (50 in the July wave). Language is held fixed, so the only things that move between waves are the models and the date. This is the paper's English arm, not its primary local-language cell. The paper's own July 2026 collection is the first wave, cut to the same slice.

What the tracker does and does not show

These are raw cell means. The tracker does not reproduce the paper's estimates: there are no country fixed effects, no wild cluster bootstrap over models, and no Holm correction for multiple comparisons. The country gaps shown are plain differences against each model's own USA cell, which is a descriptive summary and not an estimated treatment effect. The provider average in the collapsed view is an unweighted mean of that provider's models.

The July wave is the paper's main collection restricted to the tracker's slice, so its thirteen models are directly comparable with every later panel, with one difference in precision: July cells hold 50 repetitions, tracking cells 25. A difference between a July model and a September model still mixes two things — the model is newer and the query is later — and only the anchors, which are the same slug queried in both waves, separate them. Release dates are the day the slug went live on OpenRouter. In July the API returned dated snapshot names (shown as “served as” in the table view); in September it returned the bare slug, so the exact snapshot behind a September answer is not observable from the response.

Excluded from every figure, following the pre-registered rules: truncated responses, parse failures, and refusals. Also excluded, by the tracker's own rules rather than the pre-registration: zero-token provider errors, and rows from models dropped from a panel after collection had started, which the strip counts outside the total. “Slug drift” in the strip counts rows whose returned slug differs from the one every other row of that model got in the same wave. Temperature is fixed at 0.7 with no system prompt, and max_tokens is 4000, matching the main collection.
